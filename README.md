### About me

I'm a Computer Science student at the University of Hargeisa (Faculty of Engineering and Computing, class of 2028), based in Hargeisa, Somaliland. I'm focused on becoming a backend developer, with a longer-term goal of building tech ventures for East Africa.

- 🔭 Currently building **Hanti-dhawr**, a Somali-language SaaS ERP platform for Somaliland SMEs
- 🌱 Sharpening fundamentals through the **Git & GitHub Bootcamp** at Goobo Labs
- 💬 Ask me about Node.js, Express, PostgreSQL, or Somaliland tech
- ⚡ Fun fact: I write my project docs bilingual — Somali explanations, English code
